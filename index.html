Audio Settings

버퍼는 드라이버의 기본값을 사용합니다. 패널 설정을 변경한 뒤 아래의 출력 적용 버튼으로 다시 연결하세요.

재생, 일시정지, 정지, 탐색 시 발생할 수 있는 클릭/팝 노이즈를 짧은 전환 처리로 억제합니다. 기본값은 ON이며, OFF에서는 전환 처리를 완전히 건너뜁니다.

출력 장치를 전환하면 재생이 멈추고 처음으로 이동합니다. De-click만 바꾸면 현재 재생을 유지합니다.

현재 출력

드라이버 보고 지연과 callback 측정값은 실제 스피커의 청취 지연과 다릅니다.

Export Audio Mixdown

Cycle 반복과 실시간 MIDI 입력은 제외합니다. 선택 구간은 끝 경계에서 정확히 종료하며, 전체 범위는 잔향을 포함합니다.

선택 폴더 안에 새 Stem 폴더를 만듭니다. Track 순서와 이름으로 파일을 구분하며 기존 폴더와 파일은 덮어쓰지 않습니다.

Normalize / 추가 Limiter / Dither 없음 · 32-bit float는 0 dBFS 초과 값을 보존합니다. Transport De-click은 파일에 굽지 않습니다.
